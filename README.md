# Analisis Econometrico: Gasto Publico, Importaciones y Producto en Ecuador (VAR/VECM)

## 📌 Descripcion del Proyecto
Este proyecto analiza la relacion dinamica entre el Gasto de Consumo del Gobierno, las Importaciones, el PIB real y las Exportaciones No Petroleras en el Ecuador utilizando modelos econometricos de series de tiempo multivariadas (VAR / VECM).

## 📂 Estructura del Repositorio
- `data/`: Datos crudos y procesados del Banco Central del Ecuador (BCE).
- `notebooks/`: Analisis exploratorio, pruebas de raiz unitaria y diagnosticos.
- `src/`: Modulos de Python para procesamiento y estimacion econometrica.
- `agents/`: Agentes de apoyo para pipeline de datos y analisis asistido por IA.
- `outputs/`: Tablas, graficos (IRF/FEVD) y JSONs de resultados.
- `dashboard/`: Frontend interactivo para despliegue en Vercel.
- `paper/`: Documento academico en PDF (Minipaper).
- `prompts/`: Registro transparente del uso de Inteligencia Artificial.

## 🚀 Instrucciones de Ejecucion
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv venv`
3. Activar el entorno e instalar dependencias: `pip install -r requirements.txt`
